# RetroPicoES v2.1 S17-E SD delivery (noiz2sa)

The installer copies only the noiz2sa Loader artifacts. It does not create,
copy, or modify `data/noiz2sa` or `SAVES/noiz2sa`; those remain user/content
delivery inputs.

## Preconditions

Provide both delivery artifacts:

- the target UF2 (normally
  `build-pico-retropicoes-v21-bootloader-make/noiz2sa.uf2`);
- the original 320x240 Loader artwork at `assets/loader/noiz2sa.png`.

The artwork is intentionally not generated by the port build. Until it is
provided, the installer stops before touching the SD card.

## Installation

Run PowerShell with the mounted SD card as its root (for example `H:\`):

```powershell
./noiz2sa/scripts/install-noiz2sa-bootloader-sd.ps1 -SdRoot H:
```

For an explicit UF2 or artwork path:

```powershell
./noiz2sa/scripts/install-noiz2sa-bootloader-sd.ps1 `
  -SdRoot H: `
  -ApplicationUf2 C:\build\noiz2sa.uf2 `
  -ArtworkPng C:\art\noiz2sa.png
```

The script updates `emu/emulators.txt` idempotently, installs the UF2 under
`emu/16/noiz2sa.uf2`, and installs artwork under
`emu/assets/themes/0/noiz2sa.png`. Existing duplicate noiz2sa menu rows are
removed; unrelated Loader entries are preserved.

## Result interpretation

`S17 CONTENT INSTALL: PASS` means the Loader files were staged and checked by
SHA-256. The script then checks the expected noiz2sa image, audio, and XML
content under `data/noiz2sa`:

- `S17 HARDWARE READINESS: READY` — content is complete enough for the
  hardware handoff;
- `S17 HARDWARE READINESS: BLOCKED` — Loader installation succeeded, but the
  required game data is incomplete. Do not call this a hardware-ready build.

The current repository intentionally contains no commercial game data and no
Loader PNG, so a clean checkout is expected to remain `BLOCKED` until those
inputs are supplied outside version control.

## Test-only directory roots

Automated tests may pass `-AllowDirectoryRootForTest` with a temporary folder.
Do not use that switch for a real SD card: production invocations must target a
mounted drive root.
